# GMSS — 通用 MIDI 硬音源模块

> **一块硬币大小的板子，把 MIDI 键盘变成一台 128 音色的 GM 音源。**
> 不依赖电脑、不需要声卡驱动，通电就能弹。

---

## 一句话介绍

**GMSS** 是一台基于 RP2350 的**通用 MIDI（General MIDI）硬音源**。
它把标准 MIDI 信号解码后实时合成音频，通过 I2S 输出高保真模拟信号，
可直连音箱、功放或调音台。**全部音色存储在板载 16MB flash 里，插电即用。**

---

## 核心特性

| 特性 | 说明 |
|---|---|
| 🎹 **完整的 GM 音色库** | **128 个旋律音色 + 8 套鼓组**，覆盖 GM Level 1 全部音色编号 |
| 🔊 **48 kHz / 16 bit 高保真输出** | I2S 接口 + PCM5102A 解码，2.1 Vrms 线路电平输出 |
| ⚡ **16 复音** | 支持多音和弦与踏板延音 |
| 🔌 **标准 MIDI 输入** | 5 针 DIN 接口，**6N138 光耦电气隔离**，与电脑/键盘彻底隔离 |
| 💾 **离线音色库** | 6.42 MB 采样数据固化在板载 flash，**不依赖 SD 卡、不依赖电脑** |
| 🎛️ **实时控制** | 支持音量、声像、表情、延音踏板、弯音、全部音符关闭等标准 MIDI CC |
| 📟 **状态显示**（可选）| 两位数码管显示当前音色号，小数点兼作 MIDI 活动指示 |
| 🎚️ **面板按键**（可选）| 一键全部音符关闭（panic）、主音量四档切换 |
| 🩺 **自检与诊断** | 开机自动播放测试和弦；板载 LED 闪烁指示音频核心运行状态 |

## 硬件配置要点

> ⚠️ **以下五条是装配时的关键，任一条错误都会导致「完全没声音」或「MIDI 无响应」。**

### 1. PCM5102A 模块的 `XSMT` 必须接 3.3 V

`XSMT` 是软静音控制脚。**悬空时电平不定，可能被读成「静音」——
表现是 I2S 时钟全部正常、数据也在跑，但输出一点声音都没有。**

模块上这个焊盘**没有上拉电阻**，必须外部接 3.3 V（直接短接即可，它是 CMOS 输入脚）。

### 2. MIDI 光耦输出接 `GP11`，不是 `GP10`

| 引脚 | UART1 功能 |
|---|---|
| **GP10** | TX / CTS —— **不能做接收** |
| **GP11** | **RX** ✅ |

把 `GP11` 配成 UART_AUX 功能即可。**接在 GP10 上会收到任何数据**，
而且 GP10 作为 TX 时空闲输出高电平，还会把光耦输出顶住。

### 3. PCM5102A 的 `SCK` 接 GND

模块内部 PLL 从 BCK 重建主时钟。**SCK 悬空 = 没有主时钟 = 完全不出声。**

### 4. 数码管 g 段接 `GP20`

段位对应关系（**载板实测，按此接线**）：

| 段 | GPIO | | 段 | GPIO |
|---|---|---|---|---|
| a | GP15 | | e | GP21 |
| b | GP16 | | f | GP19 |
| c | GP17 | | **g** | **GP20** |
| d | GP18 | | dp | GP22 |

**位选三极管在载板上是接反的**，固件里已对调（`PIN_DIGIT1=7`、`PIN_DIGIT2=6`），
接线时按丝印接即可。

### 5. DIN pin 2（屏蔽）的处理

MIDI 规范里 pin 2 是电缆屏蔽层，**建议不接**。
若要接，用 **100 nF 陶瓷电容** 到主板地（**不要用 100 µF** ——
在 31 kHz 上它的阻抗只有 0.05 Ω，等于把屏蔽层直接接到主板地，会形成地环路引入噪声）。

## 使用说明

### 接线

```
MIDI 键盘 / 电脑 ──[MIDI 线]──> GMSS 的 MIDI IN
                                    │
                              [音频线] 3.5mm
                                    ↓
                            有源音箱 / 功放 / 调音台
供电：USB-C 5V
```

> **注意**：输出是**线路电平**，推不动耳机（32 Ω）。
> 要接耳机需要外加一级耳放（如 TDA1308）。

### 开机

1. 接上 USB-C 供电
2. **LED 闪烁** = 系统启动，音频核心运行中
3. **听到一个 C 大调和弦** = 音色库加载成功、音频通路正常
   - 若没有这个和弦，说明音色库未烧录或音频通路有问题

### 演奏

直接用 MIDI 键盘或电脑音序器发送 MIDI 即可。
常用的控制：

| 操作 | MIDI 消息 |
|---|---|
| 切换音色 | Program Change（0~127）|
| 音量 | CC 7 |
| 声像 | CC 10 |
| 表情 | CC 11 |
| 延音踏板 | CC 64 |
| **全部音符关闭** | **CC 123**（或 CC 120）|

### 关于延迟

**当前固件使用 4096 帧缓冲，MIDI 响应延迟约 85~170 ms。**
这个值对演奏来说偏大 —— 若需要更低的延迟，可将
`firmware/include/board_config.h` 里的 `BOARD_AUDIO_BUF_FRAMES`
降到 `1024`（约 43 ms），代价是对渲染实时性要求更高。

## 适用场景

- 🎹 **MIDI 键盘演奏** —— 把没有内置音源的 MIDI 键盘变成完整 GM 音源
- 🎼 **音乐制作** —— 作为 GM 回放设备，兼容标准 MIDI 文件
- 🥁 **电子鼓 / 打击板** —— 8 套鼓组覆盖 GM 鼓映射
- 🤖 **嵌入式/创客项目** —— 单片机项目需要发声时的现成方案
- 📚 **教学** —— 直观演示 MIDI 协议、数字合成、I2S 音频
- 🎮 **复古游戏 / 老电脑** —— 为老设备提供 GM 音源

## 已知限制

| 限制 | 说明 |
|---|---|
| **16 复音** | 实测硬件上限约 20 个同时发声，16 保留余量。极端密集的编曲会触发抢声部（音符被截断）|
| **无 MIDI THRU** | 不做直通转发 |
| **无音频输入** | 仅合成，不处理外部音频 |
| **线路电平输出** | 不能直接驱动耳机或小喇叭 |
| **延迟偏大** | 见上文，可通过调小缓冲改善 |

## 设计要点（供二次开发参考）

### 双核架构

| 核心 | 职责 |
|---|---|
| **core 0** | MIDI 解析、按键、显示、串口 —— **可能阻塞的操作全在这里** |
| **core 1** | 音频引擎 —— **绝不阻塞**，按时把采样块推给 I2S |

两核通过**单生产者/单消费者无锁命令队列**通信。
**MIDI 核永远不直接修改声部表** —— 否则会和音频核产生竞争，
听感是"一卡一卡的"爆音。

### 音频通路

```
MIDI 消息 → 命令队列 → 声部分配 → ADPCM 解码 → 包络/滤波 → 混音
   → 双缓冲 → DMA → PIO（I2S）→ PCM5102A → 模拟输出
```

### 关键参数位置

所有可调参数集中在 **`firmware/include/board_config.h`**：

| 参数 | 作用 |
|---|---|
| `BOARD_SAMPLE_RATE` | 采样率 |
| `BOARD_MAX_VOICES` | 复音数 |
| `BOARD_AUDIO_BUF_FRAMES` | 音频缓冲（影响延迟）|
| `BOARD_MASTER_VOLUME_PERCENT` | 主音量（默认 55%，防削顶失真）|
| `BOARD_HAS_DISPLAY` / `BOARD_HAS_BUTTONS` | 是否使用数码管/按键 |
| `PIN_*` | 全部引脚定义 |

## 烧录方法

**只需一个文件**：`GMSS_TimGM6mb_一次烧录.uf2`（12.31 MB，固件 + 音色库）

1. 按住开发板 **BOOTSEL** 键，插上 USB-C
2. 电脑出现 `RP2350` 盘
3. 把 UF2 文件拖进去
4. **等待十几秒**（USB 传输约 1 MB/s，盘自动消失即完成）

> **精简版**（不含数码管与按键）：`GMSS_精简版_无显示无按键.uf2`
