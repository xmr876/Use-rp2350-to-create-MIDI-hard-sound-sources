## 4. QSPI Flash 阵列

### 4.1 为什么这样接

- RP2350 的 QMI **原生只有 CS0（专用脚 60）+ CS1** 两路
- **CS1 的 ALT 功能是 F9 `XIP_CS1n`，低有效，RP2350A 上只有 GPIO 0/8/19 可用** ✅
- 第 3、4 片只能用**普通 GPIO 软件片选**
- 四片的 **CLK / D0 / D1 / D2 / D3 全部并联**

### 4.2 连接表

| MCU 脚 | 网络 | U1 (W25Q32) | U3/U4/U5 (W25Q128) |
|---|---|---|---|
| 60 | `FLASH_CS0` | 脚1 `/CS` | — |
| **31 (GPIO19)** | `FLASH_CS1` | — | U3 脚1 `/CS` |
| **12 (GPIO8)** | `FLASH_CS2` | — | U4 脚1 `/CS` |
| **13 (GPIO9)** | `FLASH_CS3` | — | U5 脚1 `/CS` |
| 56 | `QSPI_CLK` | 脚6 CLK | 脚6 CLK |
| 57 | `QSPI_D0` | 脚5 DI/IO0 | 脚5 DI/IO0 |
| 59 | `QSPI_D1` | 脚2 DO/IO1 | 脚2 DO/IO1 |
| 58 | `QSPI_D2` | 脚3 **/WP/IO2** | 脚3 **/WP/IO2** |
| 55 | `QSPI_D3` | 脚7 **/HOLD/IO3** | 脚7 **/HOLD/IO3** |
| — | `+3V3` | 脚8 VCC | 脚8 VCC |
| — | GND | 脚4 GND | 脚4 GND |

### 4.3 ★ 关于 /WP 和 /HOLD 的 10kΩ 上拉——网上流传的说法是错的

| 网上说法 | 事实 |
|---|---|
| "WP# 和 HOLD# 必须上拉到 3.3V，否则进不去四线模式" | ❌ **反了**。四线模式下 `/WP` 变成 **IO2**、`/HOLD` 变成 **IO3**，它们是**数据线** |
| "四线模式靠引脚拉高使能" | ❌ 四线模式由**状态寄存器 2 的非易失 QE 位**使能，与引脚电平无关 |
| "那这两个脚悬空就行" | ❌ 不好。上电到固件配置 QE 之间，悬空脚可能受干扰 |

**正确做法**：仍然给 `/WP` 和 `/HOLD` 各接 **10kΩ 上拉**（四片可共用），
但**目的不是"进四线模式"，而是保证上电到 QE 配置完成之间引脚不悬空**。
进入四线模式后 SoC 会推挽驱动这两条线，10k 太弱不会打架。

### 4.4 ★ W25Q128JV 命令集（我最初记错过，已纠正）

| 操作码 | 模式 | 说明 |
|---|---|---|
| `0x0B` | 1-1-1 | **单线 Fast Read**（**不是 0x6B**） |
| `0x3B` | 1-1-2 | Fast Read Dual Output |
| `0xBB` | 1-2-2 | Fast Read Dual I/O |
| `0x6B` | 1-1-4 | Fast Read Quad **Output** |
| **`0xEB`** | **1-4-4** | **Fast Read Quad I/O ← 我们用这条** |

固件只需实现 `0xEB` 一条读命令。初始化需要：
`0x06`(Write Enable) → `0x01`(Write Status Reg-2，置 QE 位) → `0x05`(Read Status)。
**QE 位是非易失的**，烧一次即可，但固件每次启动仍应校验。

> ⚠️ `0xEB` 的 **dummy cycle 数**需要按实际时钟频率确认（W25Q128JV 在
> 高时钟下通常是 6 个）。这部分建议在 P2 阶段用逻辑分析仪实测确认。

### 4.5 Flash 布线要求

- **CLK 走线最短且等长**（< 5cm），串一颗 **22~33Ω** 电阻抑制过冲
- 每片独立 **100nF 退耦**，紧贴 VCC 脚（< 3mm）
- 裸片和 WSOP-8 都用 **SOIC-8 封装**（W25Q128JVSIQ / W25Q32JVSSIQ）
- 片选走线不必等长，但要避免与 CLK 长距离并行

## 5. PCM5102A 模块接口

### 5.1 用 2×5 排母（推荐可插拔）

**J2：2×5 2.54mm 排母**，让模块可插拔（便于换模块、便于调试）。

| J2 脚 | 连接 | 说明 |
|---|---|---|
| 1 | `+3V3A` | VIN ← **3.3V，不是 5V** |
| 2 | GND | |
| 3 | `I2S_BCK` (GPIO12) | BCK |
| 4 | `I2S_DIN` (GPIO14) | DIN |
| 5 | `I2S_LRCK` (GPIO13) | LRCK |
| 6 | **GND** | **SCK ← 硬接地** |
| 7~10 | 预留 / 各自按模块丝印对齐 | FLT/DEMP/XSMT/FMT **不用接**（模块已配默认） |

> ⚠️ **排母的物理位置要按你手上模块的实际丝印排布来定**。
> 不同批次的模块丝印顺序可能不同（你给的图里就是
> `VIN GND FLT DEMP XSMT FMT SCK | BCK DIN LRCK`）。
> **画封装前拿实物量一遍**，别照抄我这张表的顺序。

### 5.2 ★ 三条必须遵守的规则

1. **SCK 必须硬接地**（≤ 0.3 × DVDD）。
   数据手册 SLAS859A p.12 原文：*"if BCK and LRCK start correctly while SCK remains
   at ground level for 16 successive LRCK periods, then the internal PLL starts"*。
   **悬空不行**——悬空的施密特输入可能被读成高，那就进了"外部 SCK 模式"，结果是**静音**。

2. **VIN 必须给 3.3V，绝对不能给 5V**。
   PCM5102A 绝对最大额定值是 **3.9V**，5V 会直接打坏芯片。

3. **上电顺序**：先给 SCK 地电平 → 再启动 I2S 时钟。
   且 I2S 时钟不能中途停——停超 4 个 LRCK 周期芯片会重新初始化并静音。
   这也是**必须把音频引擎放 core0 独占**的硬件级理由。

## 6. MIDI 输入

### 6.1 连接（6N138 / 6N139，**不是 6N317/6N137**）

```
DIN-5 (J3)
 脚4 ──┬── R10 220Ω ──┬── U6 脚2 (Anode)
       │              │
       │   D4 1N914 ──┤   ★ 反并联在 LED 两端，阴极朝脚4 侧
       │   (阴极朝上)  │
       │              │
 脚5 ──┴──────────────┴── U6 脚3 (Cathode)
 脚2 ── GND（可选经 0.1µF）
 脚1,3 ── NC

+5V ──┬── U6 脚8 (VCC) ── C10 100nF ── GND
      │
      └── R11 1kΩ ──┬── U6 脚6 (VO) ──► GPIO10 (MIDI_IN)
                    │
                    ├── U6 脚7 (V_B) ── R12 4.7kΩ ── GND
                    │   ★ 加速关断，必须加
                    │
U6 脚5 (GND) ───────┴── GND
U6 脚1,4 (NC) ── 悬空
```

### 6.2 为什么必须是 6N138/6N139

MIDI 1.0 电气规范 **CA-033** 对接收端的原文要求：
> *"**The receiver must require less than 5 mA to turn on.
> Rise and fall times should be less than 2 microseconds.**"*

| 器件 | 导通阈值 | 判定 |
|---|---|---|
| **6N138** | **1.6 mA** | ✅ 规范点名，约 3 倍余量 |
| **6N139** | **0.5 mA** | ✅ 余量更大 |
| PC-900V | 4 mA | ⚠️ 电气可以，但**已停产无货**（夏普 PC900 系列停产） |
| H11L1 | 1.6 mA | ⚠️ 电气可以，但**是 DIP-6** —— 与 6N138 的 DIP-8 引脚不兼容，焊盘要重画 |
| ~~6N137~~ | 推荐工作条件 **≥6.3 mA** | ❌ **超规范** |
| ~~6N317~~ | **型号不存在** | ❌ 采购不到 |
| ~~PC817 / TLP521~~ | 慢速通用光耦 | ❌ 边沿远达不到 2µs |

### 6.3 电流核算（环路一共 3 颗 220Ω）

| 位置 | 电阻 |
|---|---|
| 发送端（+5V → DIN 脚4） | 220Ω |
| 发送端（UART TX 经缓冲 → DIN 脚5） | 220Ω |
| **接收端（本板，串在 LED 前）** | **220Ω** |

(5V − 1.4V − 驱动器压降) / 660Ω ≈ **5 mA**。
6N138 阈值 1.6mA → **约 3 倍余量** ✓

> ★ **DIN-5 脚5 不是地**，是被发送端驱动器拉低的电流汇点。
> ★ 单颗 **1N914**（阴极朝脚4侧）反并联在 LED 两端，规范里只有一颗，不是"一对二极管"。

### 6.4 极性（固件必须一致）

光耦**相对电流环是反相的**（环内有电流 → 输出拉低），
但 **MIDI 逻辑 0 = 有电流**、**UART 起始位也是低**，
所以到 RX 脚极性**正好是对的** → **不要加反相器**。

## 7. 数码管与按键

### 7.1 数码管（2 位共阴，动态扫描）

```
              +3V3
               │
   段线：GPIO ── R(330Ω) ── 数码管段脚 a~g
               │
   位选：GPIO23 ── R(1kΩ) ── Q1 基极 (MMBT3904)
                          Q1 集电极 ── 数码管 COM1
                          Q1 发射极 ── GND

         GPIO24 ── R(1kΩ) ── Q2 基极 (MMBT3904)
                          Q2 集电极 ── 数码管 COM2
                          Q2 发射极 ── GND
```

| 网络 | MCU 脚 | GPIO |
|---|---|---|
| `SEG_A` | 19 | GPIO15 |
| `SEG_B` | 20 | GPIO16 |
| `SEG_C` | 27 | GPIO17 |
| `SEG_D` | 28 | GPIO18 |
| `SEG_E` | 32 | GPIO20 ← **跳过 GPIO19**（它给了 CS1） |
| `SEG_F` | 33 | GPIO21 |
| `SEG_G` | 34 | GPIO22 |
| `DIG1` | 35 | GPIO23 |
| `DIG2` | 36 | GPIO24 |

**计算**：
- 段电流 (3.3 − 1.9) / 330 ≈ **4.2 mA/段**
- 8 段全亮时单管集电极电流 34 mA，MMBT3904（200mA）完全承受得住
- **必须用三极管，别省**：RP2350 单脚上限 12mA，8 段共 34mA 超了

> ⚠️ **GPIO19 的冲突是硬约束**：它既是数码管段线的好位置，
> 又是 RP2350A 上仅有的 3 个 CS1 可用脚之一。**CS1 优先**，段线跳过它。

### 7.2 按键

```
BTN1: GPIO25 ──┬── SW2 ── GND
               └── R 10kΩ ── +3V3
               └── C 100nF ── GND

BTN2: GPIO26 ──┬── SW3 ── GND
               └── R 10kΩ ── +3V3
               └── C 100nF ── GND
```

**不要依赖内部上拉**：RP2350 内部上拉约 50~80kΩ，抗干扰差。
外部 10kΩ + 100nF 做软硬件双重消抖。

### 7.3 状态 LED

`GPIO27`（脚41）── R 1kΩ ── LED ── GND

用途：心跳指示、Flash 读错误指示、复音溢出指示。

## 8. 调试接口

| 网络 | MCU 脚 | 说明 |
|---|---|---|
| `SWCLK` | 24 | 3 针排针：SWCLK / SWD / GND |
| `SWD` | 25 | 间距 2.54mm |
| `RUN` | 26 | 10kΩ 上拉到 3V3 + 100nF 到 GND + 复位按键 |
| `GND` | — | |

**BOOTSEL 怎么进**：RP2350 没有专用 BOOTSEL 按键脚。
标准做法是**在上电瞬间把 QSPI CS 拉低**。两种实现：
- **方案 A（推荐）**：做一个按键把 `FLASH_CS0`（脚60）短到 GND，
  上电时按住即可。**注意这会和 U1 的片选冲突**，所以串一颗 1kΩ 限流。
- **方案 B**：靠固件实现"插上 USB 自动进 BOOTSEL"（用 `reset_usb_boot()`），
  按一下 BTN1 就触发，无需额外按键。**优先用这个，省一个按键。**

## 11. PCB 布局要求

| 项目 | 要求 |
|---|---|
| 层数 | **4 层**（信号 / GND / 3V3 / 信号） |
| 板尺寸 | 建议 100 × 80 mm |
| **GND 平面** | **完整不分割**。QSPI 回流靠它 |

| **QSPI CLK** | 最短、< 5cm、串 22Ω、不跨分割 |
| **USB 差分对** | 90Ω 差分阻抗，等长误差 < 0.15mm |
| **晶振** | 紧贴 MCU（< 10mm），下方**挖空铺铜**，周围包地过孔 |
| **散热焊盘** | RP2350A 底部焊盘**多打 9~16 个过孔**到 GND 平面 |
| **去耦电容** | 100nF 紧贴对应电源脚（< 3mm） |
| 数码管 | 远离模拟区，避免扫描噪声耦合 |
| 丝印 | `+5V` / `GND` 焊盘标注清楚，`≤5.5V` |

## 13. 一个更省事的替代路线

**如果你不想一次画完整板**，建议先做**最小验证板**：

用 **Pico 2 模块**（不是裸片）+ PCM5102 模块 + 1 片 W25Q128 模块，
用杜邦线连起来，验证"能出声"和"能从 Flash 读采样"这两件事。

- 成本：≈ 60 元
- 时间：**2 天**
- 收益：验证掉全局风险最高的两件事（I2S 时钟 + QSPI 多片驱动），
  **省掉一次打板**

验证通过后再画正式 PCB，此时本文档的所有内容都已被实践检验过一遍。
