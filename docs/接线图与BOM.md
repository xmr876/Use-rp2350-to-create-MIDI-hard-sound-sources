# 接线图 + BOM（RP2350 16MB 开发板 + PCM5102 模块）

> 硬件：**RP2350 开发板（板载 16MB Flash，USB-C）** + PCM5102 模块
> + 6N138 光耦 + DIN-5 MIDI 输入 + 2 位共阴数码管 + 2 按键
> 供电：开发板 USB-C 口

---

## 0. 先说三个结论

| | |
|---|---|
| **不用魔改 Flash** | 你选的这块板**自带 16MB**，省掉了换取 Flash 那一步 |
| **不用第二片 Flash** | 音色库和固件同住这 16MB，**内存映射**直读，一行驱动都不用写 |
| **PCM5102 的 VIN 必须接 3.3V** | **接 5V 会烧芯片**（绝对最大额定 3.9V）。这是最容易犯的致命错误 |

## 1. 开发板引脚识别

你给的板子**与官方 Pico / Pico 2 的 40 脚定义完全一致**（已按实物照片逐脚核对）。

板上丝印的写法：**GPIO 只印数字**（`0` `1` `2` … `22` `26` `27` `28`），
GND 印成 `G`，电源脚印 `VBUS` / `VSYS` / `3V3` / `3V3EN` / `VR` / `RUN`。

```
                  ┌───── USB-C ─────┐
        GP0   (1) │●               ●│ (40) VBUS
        GP1   (2) │                 │ (39) VSYS
        GND   (3) │                 │ (38) GND
        GP2   (4) │                 │ (37) 3V3_EN
        GP3   (5) │                 │ (36) 3V3      ← 给 PCM5102 供电
        GP4   (6) │   RP2350A       │ (35) VR / ADC_VREF
        GP5   (7) │   16MB Flash    │ (34) GP28
        GND   (8) │   BOOT / USER   │ (33) AGND
   ★   GP6   (9) │   RGB LED       │ (32) GP27
   ★   GP7  (10) │                 │ (31) GP26
   ★   GP8  (11) │                 │ (30) RUN
   ★   GP9  (12) │                 │ (29) GP22  ★
        GND  (13) │                 │ (28) GND
   ★   GP10 (14) │                 │ (27) GP21  ★
   ★   GP11 (15) │                 │ (26) GP20  ★
   ★   GP12 (16) │                 │ (25) GP19  ★
   ★   GP13 (17) │                 │ (24) GP18  ★
        GND  (18) │                 │ (23) GND
   ★   GP14 (19) │                 │ (22) GP17  ★
   ★   GP15 (20) │                 │ (21) GP16  ★
                  └─────────────────┘
```

★ = 本工程用到的脚。

> **以板上丝印为准。** 上表的物理脚号是 Pico 标准，你这块板子目视一致；
> 但插线前请对一下丝印上的数字，不要只按位置数。

## 3. 接线图

### 3.1 PCM5102 模块（6 根线）

```
   RP2350 开发板                    PCM5102 模块（6 脚排针）
   ┌──────────────┐                ┌──────────────────────┐
   │              │                │  VIN  GND  LRCK  DIN │
   │  3V3 (36) ───┼────────────────┼─►VIN                 │  ★ 必须 3.3V
   │  GND  (38) ──┼────────────────┼─►GND                 │
   │  GP12 (16) ──┼────────────────┼─►LRCK                │
   │  GP14 (19) ──┼────────────────┼─►DIN                 │
   │  GP13 (17) ──┼────────────────┼─►BCK                 │
   │              │                │                      │
   │  GND  ───────┼────────────────┼─►SCK   ★ 接 GND！     │
   └──────────────┘                │      BCK  SCK        │
                                    └──────────────────────┘
```

**模块排针顺序（按你的图，从板边往板内数）：**
`VIN`、`GND`、`LRCK`、`DIN`、`BCK`、`SCK`

**三条硬规则：**

1. **`VIN` 接 3.3V，不是 5V。**
   模块上 `VIN` 直连 PCM5102A 的电源脚，而 PCM5102A 绝对最大额定电压是 3.9V。
   接 5V 会立刻打坏芯片。**这是全套接线里唯一会烧东西的地方。**

2. **`SCK` 接 GND。**
   这样 PCM5102A 用**内部 PLL 从 BCK 重建主时钟**，省掉一路 MCLK，
   也就不用从 RP2350 再引一根时钟线。
   > 先量一下：很多批次的模块背面已经把 SCK 通过跳线接地了，
   > 那样就不要再接了（重复接地无害，但要确认不是接成了上拉）。
   > 如果模块背面有 `H1L`~`H4L` 一类的焊盘跳线，**保持出厂状态别动**。

3. **模块上其余标注不用接**：
   `FLT` / `DEMP` / `XSMT` / `FMT` 是配置脚，模块板上已有默认电阻；
   `A3V3` / `AGND` / `ROUT` / `AGND` / `LROUT` 是模拟侧，已经连到 3.5mm 座和电位器。
   **只接那 6 根就够了。**

**输出**：模块自带 3.5mm 耳机座，可直接插耳机或有源音箱。
接**无源音箱**需要额外功放（模块输出驱动不了）。
模块上的电位器是模拟音量，建议拧到较大位置，用固件控制音量。

### 3.2 MIDI 输入（DIN-5 五脚母座 + 6N138）

```
                    ┌─────────────────────────────┐
   DIN-5 母座        │  3.3V                       │
   (从正面看插座)     │    │                        │
                    │    ├── 1kΩ ──┬──────────────┼──► GP10 (14)  UART1 RX
     1   3          │    │         │              │
   2       5        │    │       ┌─┴─┐            │
      \   /         │    └───────┤ 6 │ VO         │
       ───          │            │   │            │
       (4)          │      ┌─────┤ 5 │ GND ── GND │
                    │      │     │   │            │
   pin4 ──220Ω──┐   │      │   ┌─┤ 7 │ VB         │
                │   │      │   │ │   │            │
   pin5 ────────┼───┼──────┼───┼─┤ 3 │ Cathode    │
                │   │      │   │ │   │            │
   pin2 ──100nF─┴─GND│      │   │ │ 2 │ Anode ─────┼── 220Ω pin4
                    │      │   │ └───┘            │
                    │      │   └── 4.7kΩ ── GND   │
                    │      └────── 6N138          │
                    │  pin8 ── 3.3V, 100nF 到 GND  │
                    └─────────────────────────────┘
```

**DIN-5 五脚接法：**

| DIN-5 脚 | 接到 | 说明 |
|---|---|---|
| **1** | 不接 | MIDI 规范未使用 |
| **2** | 100nF → GND（或直接悬空） | 屏蔽/地 |
| **3** | 不接 | MIDI 规范未使用 |
| **4** | 220Ω → 6N138 **pin2**（Anode） | 电流源 |
| **5** | 6N138 **pin3**（Cathode） | 电流汇 |

**6N138（DIP-8）接法：**

| pin | 名称 | 接到 |
|---|---|---|
| 1 | NC | — |
| 2 | Anode | DIN pin4 经 220Ω |
| 3 | Cathode | DIN pin5 |
| 4 | NC | — |
| 5 | GND | GND |
| **6** | **VO** | **1kΩ 上拉到 3V3**，同时接 **GP10** |
| **7** | **VB** | **4.7kΩ 到 GND**（加速关断） |
| 8 | VCC | 3V3（就近并 100nF 到 GND） |

> **★ 上拉必须是 1kΩ，不是常见的 10kΩ。**
> 6N138 输出是达林顿，等效输出电容大。10k 上拉时上升沿要几十微秒，
> 而 31250 bps 的位宽只有 32 µs —— 波形直接糊掉，表现为随机丢字节。
>
> **★ 光耦必须是 6N138 / 6N139，不能用 6N137。**
> 6N137 是逻辑输出型，保证工作需要 ≥6.3 mA；
> 而 MIDI 电气规范（CA-033）要求接收端在 **5 mA 以下**就能可靠翻转。
> 用 6N137 的症状是"有些设备能收，有些完全收不到"。
>
> ⚠️ **注意 H11L1 / PC900V 是 DIP-6，与 6N138 的 DIP-8 引脚不兼容**，
> 不能直接替换（PCB 焊盘要重画）。而且 PC900V 已停产无货。
> **按 6N138（DIP-8）画板就行**，立创现货充足 ——
> 详见 §5.7，那里有替代料的完整说明。
>
> **极性**：MIDI 空闲时电流环无电流 → 光耦不导通 → VO 被上拉到高 → UART 空闲高 ✓。
> 起始位＝有电流 → VO 拉低 ✓。**极性正好，不要加反相器。**

**MIDI THRU（可选）**：GP11 → 100Ω → 另一个 DIN-5 的 pin5；
3V3 → 100Ω → 该 DIN-5 的 pin4。不装不影响 MIDI 输入。

### 3.3 2 位共阴数码管

```
         3.3V
          │
    ┌─────┴─────┬─────┬─────┬─────┬─────┬─────┬─────┐
    │           │     │     │     │     │     │     │
   180Ω       180Ω  180Ω  180Ω  180Ω  180Ω  180Ω  180Ω
    │           │     │     │     │     │     │     │
   GP15       GP16   GP17  GP18  GP19  GP20  GP21  GP22
    │           │     │     │     │     │     │     │
    a           b     c     d     e     f     g     dp
    │           │     │     │     │     │     │     │
   ┌┴───────────┴─────┴─────┴─────┴─────┴─────┴─────┴┐
   │            2 位共阴数码管                        │
   │   D1 (共阴)                        D2 (共阴)     │
   └────┬──────────────────────────────────┬─────────┘
        │                                  │
        │  ┌──────┐                 ┌──────┐
        └──┤ C  S8050                C  S8050 ├──┘
           │  E                      E  │
    GP6 ─1kΩ─┤ B                      B ├─1kΩ─ GP7
           │                             │
          GND                           GND
```

**要点：**

1. **段线串 180Ω**（每段一个，共 8 个）。
   @3.3V、红光 Vf≈2.0V 时峰值约 6 mA，两位各占 50% 占空 → 平均 3 mA/段。
   觉得暗可以换 120Ω，**不要再小**（RP2350 单脚最大 8 mA）。

2. **位选必须经 NPN 三极管**（S8050 / MMBT3904 / 2N3904）。
   一位点亮时最多 8 段同时导通，阴极要灌 **约 48 mA**，
   而 RP2350 单个 pad 只有约 8 mA 能力 —— 直接灌会烧 pad，
   或者亮度惨不忍睹还干扰旁边的 I2S 信号。
   共阴数码管的位选脚是**阴极**，要往下灌电流，所以用 NPN：
   发射极接 GND，集电极接位选脚，基极经 1kΩ 接 GPIO。
   **GPIO 高电平 → 导通 → 该位亮。**

3. **段线 GPIO15~21 是连续的**，固件用一次 32 位掩码写更新整组段码，
   切换时不会出现"半新半旧"的鬼影。

### 3.4 按键

```
   3.3V
    │
   （内部上拉已够用，外部 10kΩ 可选）
    │
   GP8 ──┬──── 按键1 ──── GND
         │
       100nF
         │
        GND

   GP9 ──┬──── 按键2 ──── GND
         │
       100nF
         │
        GND
```

RP2350 每个 GPIO 都有内部上拉（约 50~80 kΩ），**外部 10 kΩ 可以省**。
按键引线较长（>10 cm）时建议还是加上，抗干扰更好。
**100 nF 消抖电容建议保留**（配合内部上拉构成约 5 ms 的 RC）。

## 4. 电流预算

| 负载 | 电流 |
|---|---|
| PCM5102 模块 | ~30 mA |
| 数码管（8 段 × 6 mA × 50% 占空） | ~48 mA |
| 6N138 光耦 | ~10 mA |
| 板载 RGB LED | ~5 mA |
| **合计** | **~93 mA** |

开发板的 3V3 输出能力远超这个数，**直接从 `3V3` 排针取电即可**。

**★ 想脱离电脑当独立音源用**：把外部 5V 接到 **`VBUS`** 脚（不是 3V3！），
串一颗 SS34 肖特基防止倒灌。**千万不要把 5V 灌到 `3V3` 脚上。**

### 5.6 ★★ 下单前必读：三个"长得一模一样"的陷阱件

这三条是核实编号时**实际发现**的，都是搜索时很容易命中的东西。
买错的后果分别是不工作、不工作、整片不亮。

#### 陷阱 1：`MINI5P 180` 不是 MIDI 座，是 **Mini-USB 座**

搜索"MIDI插座 5P 180度"时很容易撞上 **C6331167**（首韩 SHOU HAN，
型号写着 `MINI5P 180 T`，中文名"5P直插母座"）——
但它的英文描述是 `USB-Mini B Receptacle Connector 5 Position Through Hole`，
**是 Mini-USB Type-B 母座，完全不能当 MIDI 座用。**

**怎么确认买对了**：商品目录必须是 **"圆形DIN连接器 / Circular Connector
Assemblies"**；图片是**圆形带定位缺口（keyway）**的金属/黑色圆壳，
5 根针呈 **180° 弧形**排列。

#### 陷阱 2：同厂同封装只差一位数字 —— **6N137 ≠ 6N138**

| 型号 | 立创编号 | 能不能用 |
|---|---|---|
| **6N138-L**（光宝） | **C571211** | ✅ **就是它** |
| 6N137-L（光宝） | C92648 | ❌ 同品牌、同 DIP-8、同 `-L` 后缀，只差一个数字 |
| 6N137M（安森美） | C5344 | ❌ 现货 28833，**最容易被配单员"顺手"替换掉** |
| 6N137-000E（博通） | C14750 | ❌ |

**为什么不能用 6N137**：它是逻辑输出型光耦，保证工作需要 **≥6.3 mA** 的
LED 电流；而 MIDI 电气规范（CA-033）要求接收端在 **5 mA 以下**就能可靠翻转。
症状是"有些设备能收，有些完全收不到"。

#### 陷阱 3：数码管的**共阳孪生兄弟**和"后缀不代表极性"

方舟（ARKLED）同系列**共阳版外观、尺寸、脚位完全一样**，买错就是整片不亮：

| 立创编号 | 型号 | 规格 | |
|---|---|---|---|
| **C193138** | SN420362N | 0.36" 红 **共阴** | ✅ **就是这个** |
| C193139 | SN410362N | 0.36" 红 **共阳** | ❌ 孪生兄弟 |
| C96556 | SN620362B | 0.36" **共阴但蓝色** | ❌ 颜色不符 |
| C118534 | — | 0.56" 共阴 | ✅ 想要大一点的选这个 |
| C193143 | SN450561N | 0.56" 红 共阳 | ❌ |
| C105655 | SN450401N | 0.4" 红 共阳 | ❌ |
| C182258 | SN430281N | 0.28" 红 共阳 | ❌ |

**★ 注意：ARKLED 型号结尾的字母不代表极性。**
`SN620362B` 结尾是 B 却是共阴。**必须看参数表里的 `LED Polarity` 字段**，
不能靠型号后缀猜。

**C193138 的 10 个脚已逐脚核实**（接线时对得上）：
`1:G  2:DP  3:A  4:F  5:DIG2  6:D  7:E  8:C  9:B  10:DIG1`

### 5.7 关于"光耦替代"的一个重要更正

我之前在文档里把 **PC-900V / H11L1** 和 6N138 并列成"都可以"，
**这个说法不准确，这里更正**：

| 型号 | 封装 | 能不能直接替换 6N138 |
|---|---|---|
| 6N138 / 6N139 | **DIP-8** | — |
| H11L1 | **DIP-6** | ❌ **脚数和引脚定义都不同，PCB 焊盘要重画** |
| PC-900V | DIP-6 | ❌ 同上，**而且夏普这个系列已停产，立创无货** |

H11L1 和 PC900V 彼此引脚兼容，但**和 6N138 不兼容**。
所以：**PCB 上要么只留 DIP-8 焊盘，要么额外留一组 DIP-6 焊盘**，
不能指望缺货时直接插上去。

目前 **C571211（6N138-L）现货充足**，按它画板就行。
真缺货时的替代顺序：C3001991（UMW 6N138M，DIP-8，便宜但 MOQ 5）
→ C17508946（博通 6N138-000E，DIP-8，贵 5 倍）
→ 最后才是换 DIP-6 的 H11L1（C78588，亿光，现货 2025）。

> ⚠️ 海外资料里常引用的 **ISOCOM 6N138 = C255743 目前库存为 0**，不要下单。
> 同样 **BOOMELE 排母 C50984 也是 0 库存**，已用 C2905423 替代。

## 6. 上电前的检查清单

按顺序做，每一步都能省掉一次返工：

- [ ] **量 PCM5102 模块 `VIN` 对 GND 是不是 3.3V**（绝不能是 5V）
- [ ] 确认 `SCK` 是接 GND，不是接 3V3（量模块背面跳线）
- [ ] 6N138 的 pin6 上拉是 **1 kΩ**（不是 10 k）
- [ ] 6N138 的 pin7 有 **4.7 kΩ 到 GND**
- [ ] 数码管是**共阴**（万用表二极管档：黑笔接位选脚、红笔接段脚应导通发亮）
- [ ] 三极管方向没装反（S8050 是 **E-B-C**，TO-92 封装平面对着自己是 EBC）
- [ ] 3V3 对 GND 没有短路
- [ ] 先不插 PCM5102 模块和数码管，只插 USB，看开发板 RGB 灯是否正常
- [ ] 再逐个插上模块，每插一个量一次 3V3

## 7. 引脚分配对应的固件配置

全部定义在 `firmware/include/board_config.h`，改引脚只需改这一个文件：

```c
#define PIN_I2S_LRCK       12      /* → PCM5102 LRCK  */
#define PIN_I2S_BCK        13      /* → PCM5102 BCK   */
#define PIN_I2S_DIN        14      /* → PCM5102 DIN   */

#define PIN_MIDI_RX        10      /* ← 6N138 VO（UART1，AUX 功能 F11）*/
#define PIN_MIDI_TX        11      /* → MIDI THRU（可选）*/

#define PIN_SEG_A          15      /* 段 a~g + dp，连续 8 根 */
#define PIN_SEG_B          16
#define PIN_SEG_C          17
#define PIN_SEG_D          18
#define PIN_SEG_E          19
#define PIN_SEG_F          20
#define PIN_SEG_G          21
#define PIN_SEG_DP         22

#define PIN_DIGIT1          6      /* 位选，经 NPN */
#define PIN_DIGIT2          7

#define PIN_BTN_UP          8
#define PIN_BTN_DOWN        9

#define PIN_LED_STATUS      PICO_DEFAULT_LED_PIN   /* 板载灯 */
```

**两条硬约束**（源码里有编译期断言，改错会直接编译报错）：

1. **`LRCK`、`BCK`、`DIN` 必须是连续的三个 GPIO**（当前 12/13/14）。
   I2S 用 PIO 的 side-set 输出 LRCK/BCK，out 引脚必须紧跟在 side-set 之后。
2. **段线 GPIO15~22 必须连续**，这样整组段码能一次写完。
