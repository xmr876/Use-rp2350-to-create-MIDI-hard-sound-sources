## 四、MIDI 输入电路

**标准 6N138 隔离输入，元件齐全：**

```
DIN-504 pin 4 ──[R1 220Ω]──> U1 pin 2 (ANODE)
DIN-504 pin 5 ─────────────> U1 pin 3 (CATHODE)
DIN-504 pin 2 ── 屏蔽层，见下文处理

                              U1 pin 5 (GND)  ──> GND
                              U1 pin 6 (VO)   ──[R2 1kΩ 上拉]──> VCC(3V3)
                                              └──> G11
                              U1 pin 7 (VB)   ──[R3 4.7kΩ]──> GND
                              U1 pin 8 (VCC)  ──> VCC(3V3) + C 100nF
```

### ★ 隔离边界

**`ANODE` / `CATHODE` 两个网络是浮空的隔离侧，不与任何地相连。**

| 隔离侧（浮空）| 主板侧 |
|---|---|
| `DIN4` → `R1` → `U1 pin2` | `U1 pin5` → GND |
| `DIN5` → `U1 pin3` | `U1 pin6` → `R2` → 3V3，并接 `G11` |
| | `U1 pin7` → `R3` → GND |
| | `U1 pin8` → 3V3 + 100nF → GND |

### ★ DIN pin 2（屏蔽层）

| 做法 | 评价 |
|---|---|
| **不接** | ✅ 最彻底，推荐 |
| **100 nF 陶瓷 → 主板 GND** | ✅ 兼顾抗射频，且信号频段隔离 |
| ~~100 µF → 主板 GND~~ | ⚠️ **不推荐**：31 kHz 时阻抗仅 0.05 Ω，等于把屏蔽层直接接到主板地，形成地环路 |

**如果板上已经放了 100 µF，建议并联一颗 100 nF 陶瓷**（电解的高频特性差，挡不住射频）。

## 五、I2S 与 PCM5102 模块

**`P1` 是 6P 排母，模块竖插。引脚顺序按模块丝印：**

| 模块脚 | 网络 | 接到 |
|---|---|---|
| VIN | `VIN` | 3V3 |
| GND | `GND` | GND |
| LRCK | `LCK` | **GP12** |
| DIN | `DIN` | **GP14** |
| BCK | `BCK` | **GP13** |
| **SCK** | `SCK` | **GND** ← 必须 |

### ★★ 模块背面的 `XSMT` 焊盘必须接 3.3 V

**`XSMT` 是软静音控制脚。这个模块上它没有上拉电阻，悬空时电平不定。**

**症状：I2S 时钟全部正常（LRCK 1.6V、BCK 1.0V）、数据也在跑，但输出一点声音都没有。**

直接短接到 3.3 V 即可（CMOS 输入脚，安全）。

> **如果 P1 是固定 6P 排母，XSMT 只能从模块背面焊盘飞线。**
> 建议在载板上预留一个 `XSMT` 焊盘或过孔，方便飞线。

## 六、数码管与按键

### 段位映射

| 段 | GPIO | | 段 | GPIO |
|---|---|---|---|---|
| a | GP15 | | e | GP21 |
| b | GP16 | | f | GP19 |
| c | GP17 | | **g** | **GP20** |
| d | GP18 | | dp | GP22 |

### ★ 位选三极管是接反的

载板上两个位选三极管（S8050）的集电极相对固件预期是**对调**的。

**固件里已经对调补偿**（`PIN_DIGIT1 = 7`、`PIN_DIGIT2 = 6`），接线按丝印做即可。

**若以后重画板子**：把两个三极管集电极对调回来，同时把固件里的
`PIN_DIGIT1` / `PIN_DIGIT2` 改回 6 / 7。

### ★ g 段走线

设计上 g 段接到了 GND。**当前实物是飞线到 GP20 修正的。**

**重画板子时改为直接连 GP20，并在固件里保持 `PIN_SEG_G = 20`。**

## 七、PCB 布局要点

### 铺铜

| 层 | 做法 |
|---|---|
| **底层** | 完整 GND 铺铜（地平面）|
| **顶层** | 也铺 GND，补全/屏蔽/散热 |
| **两层之间** | **缝合过孔**连接，间隔 5~10 mm |

**要点：**

1. **两层地必须用缝合过孔连成一体** —— 否则只是两块孤立铜皮
2. **音频输出附近（P1 那一片）加密过孔**
3. **消除孤岛** —— 不接任何网络的铜皮是天线
4. **GND 焊盘用热焊盘（十字连接）**，大电流过孔用全连接

### 数码管电流回路

**段电流是脉冲（扫描驱动），回路要短而粗。**

**关键：不要让数码管的脉冲电流从 PCM5102 的地线上流过。**

### 光耦下方

**建议在光耦本体下方设禁止铺铜区（挖空），跨过器件中线。**

避免隔离侧和主板侧通过铜皮耦合。

### 地平面分割

**不分割，用一整片地。**

模块化设计里模拟部分在 PCM5102 模块内部，分不到；而分割地处理不好比不分割更糟。
I2S 只有 3 MHz，单一地平面完全够。

## 九、装配检查清单

装完通电前逐条确认：

| # | 检查项 | 现象（若做错）|
|---|---|---|
| 1 | **PCM5102 模块 `XSMT` 接 3.3 V** | 完全没声音 |
| 2 | **PCM5102 模块 `SCK` 接 GND** | 完全没声音 |
| 3 | **光耦输出接 GP11（不是 GP10）** | MIDI 无响应 |
| 4 | **数码管 g 段接 GP20（飞线）** | 显示 `8` 时中间横不亮 |
| 5 | **DIN pin 2 处理** | 不接最省事；接了可能引入底噪 |
| 6 | **光耦 pin 5/7/8 接主板地，pin 2/3 浮空** | 隔离失效 |
| 7 | **USB 供电后 LED 闪烁** | 不闪 = 固件没跑起来 |
| 8 | **开机听到 C 大调和弦** | 不响 = 音色库或音频通路有问题 |

**用万用表验证隔离：**

| 测量 | 应该 |
|---|---|
| `DIN pin4` ↔ 主板 GND | **不通** |
| `DIN pin5` ↔ 主板 GND | **不通** |
| 光耦 `pin5` ↔ 主板 GND | 导通 |
