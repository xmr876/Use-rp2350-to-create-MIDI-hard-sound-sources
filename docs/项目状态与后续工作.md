## 开发过程中已确认的关键结论（避免重走弯路）

### 硬件选型

| 项 | 结论 | 依据 |
|---|---|---|
| MIDI 光耦 | **6N138 / 6N139**，不是 6N317（不存在）也不是 6N137（不达标） | MIDI 规范 CA-033 要求接收端 <5mA 导通；6N137 要 ≥6.3mA |
| 光耦供电 | **必须 5V**，上拉用 **1kΩ** | 规范只约束边沿 <2µs |
| PCM5102A VIN | **3.3V，绝不能 5V** | 绝对最大额定 3.9V |
| PCM5102A SCK | **硬接地** | 悬空会进外部时钟模式 → 静音 |
| CS1 引脚 | **GPIO19**（RP2350A 仅 0/8/19 可用） | OTP FLASH_DEVINFO + 勘误 E14 |
| 启动盘 | W25Q32 (4MB) 足够 | 固件约 200KB |

### 固件关键参数

| 项 | 值 | 说明 |
|---|---|---|
| 采样率 | 48000 Hz | 不是 44100（分频无法精确表示） |
| PIO I2S | 每 bit **10** 个 SM 周期 | 必须与 `.pio` 循环体一致 |
| 分频 | `4 + 226/256` | 精确，零抖动 |
| MIDI UART | **UART1**（F11） | GPIO10/11 上没有 UART0 |
| Flash 访问 | **QMI Direct Serial Mode** | 能读能写；PIO 只能读 |
| Flash SCK | 18.75 MHz（CLKDIV=4） | 吞吐 2.34 MB/s，余量 1.63 倍 |
| Flash 读命令 | `0x0B`（单线） | direct 模式只支持 SPI mode 0 |

### 必须遵守的约束

- **direct 模式期间不能执行 flash 里的代码**（会总线错误）
  → 相关函数都标了 `__not_in_flash_func`
- **CS1 的 pad 必须自己配**（勘误 E14），见 `flash_direct.c::flash_direct_init`
- **PIO 分频必须运行时算**（复位瞬间 clk_sys 不是 150MHz）
- **每复音 2KB 采样缓存**是 Flash 带宽方案成立的前提
